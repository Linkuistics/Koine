# Settings activation design discussion

The [decision document](../../../specs/settings-activation-discrimination.md)
owns the evidence limits, proposed scope amendment and unchanged acceptance duties.
The current decision is to keep all route and modality guests unstarted. Antony's
scope choice remains pending.

The proposal permits design of a justified correction using one activation
request, with explicit repetition, deferral and speculative-yield exclusions.
No candidate is established. Retaining the causal prerequisite needs a supported
prediction that excludes an outcome; an unrestricted intermittent rival has no
finite counterexample. A rate model would require an agreed statistical standard.
