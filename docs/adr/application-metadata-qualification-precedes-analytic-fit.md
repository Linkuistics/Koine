# Application metadata qualification precedes analytic fit

Application metadata may use a private guarded implementation to perform the
existing N5/N8/V11/V13 useful qualification before a complete analytic useful-fit
certificate exists. A complete private qualification design, mandatory whole-producer
review and any earned integration precede that implementation. Advertisement and
downstream consumption remain held until the declared full native operands, actual
complete selected responses, required useful witnesses and independent serviceability
qualify through the existing public GraphQL, actual provider/host binary and isolated
signed supported-macOS VM seams. The [workspace contract](../specs/workspace-search.md#private-application-qualification-order)
defines this boundary.

The [grouped refinement](../verification/application-metadata-grouped-storage.md#failed-controlled-enclosure)
improves known work but its partial conservative enclosure still exceeds the
selected 20 MiB gate. It supplies neither useful fit nor proof that actual native
work must overflow. Full native operands and final selected responses cannot be
inferred from the saved disk dimensions. Guarded finite qualification supplies
that missing evidence while retaining refusal before unadmitted explicit work.
No reader implementation or native pass follows the ordering decision alone.

The [explicit-work accounting decision](application-metadata-accounting-covers-explicit-work.md),
runtime gates, fixed file and locale/source breadth, provider-owned publication,
authority, action limits, disclosures, compatibility and independent Settings/location/
core gates remain binding. Refused or unknown required useful metadata, shared
exhaustion, response replacement, deadline failure or an unavailable required subject
cannot establish useful qualification. Such cases keep the consumption hold and
the affected acceptance work live; correct refusal controls do not pass usefulness.

Requiring an analytic certificate before any implementation would retain the
current hold after the bounded refinement failed without settling actual execution
or response dimensions. That ordering is rejected for this private qualification
route. Reconsider it if a concrete complete representation or derived envelope
establishes useful fit independently; larger amounts alone do not supply missing
operands. This selection changes no gate, scope, ABI, helper, signing or consent
posture and approves no useful-category reduction.
