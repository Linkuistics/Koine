## Goal

Deliver Koine's special starting locations and named native catalogues, initially
applications and modern System Settings destinations on macOS 26+. Clients own
raw filesystem search, its permissions, filtering/ranking/MRU and clipboard.
Existing explicit launch/open/reveal actions retain their independent contracts.

## Done when

- Reviewed native design supplies useful special locations and named catalogues
  with honest empty/blocked/unavailable/incomplete/unknown observations. Declared
  sources and source limits do not claim an unsupported exhaustive all-disk
  inventory or silently lose the configured launchers, Safari/Finder or settings.
- Koine's own reads are prompt-free and avoid hydration, qualified on actual
  provider/host binaries and signed supported VMs. A returned location grants
  no client access, contents listing or consent.
- Authority allocation, operation trace and source/native-binary call-path
  inspection preserve independently controlled action guarantees and qualify
  each actual native mechanism's effects, blocking, cleanup and serviceability.
  Earlier find permission selects no catalogue child or arbitrary process control.
- Actual G/N/V catalogue/location observations and appropriate selected actions
  are accepted, with independently retained action-only 1.0.0/1.0.1 compatibility
  and exact new provider/profile subjects. Unavailable subjects remain live work.
- All mixed live charters and consumer artifacts are reconciled to the reviewed
  scope before implementation. Concrete useful native coverage gaps require
  resolution before baseline; client raw-search ordering/coverage is not Koine work.
