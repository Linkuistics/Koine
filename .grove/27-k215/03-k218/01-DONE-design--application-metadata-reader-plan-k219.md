## Decisions (running log)

- Adopt the first design child after k218's authorized decomposition. The
  selector is an opaque pure CF boundary supplied explicit value arrays; the
  model checks saved returned arrays and branch policy, not a reimplementation
  of CF matching. No current installed target or selector is re-run after the
  development-host upgrade.
- Select base-first name traversal: global then direct selector/Base/development
  directories; within each base platform strings, plain strings, platform
  loctable, plain loctable. Each table selects over its own literal non-reserved
  key inventory. This preserves the prior first-usable-base contract and closes
  the previously missing format. Family-first across every directory would make
  a later localized strings file override an earlier usable global table; reject
  that change. No private Bundle equivalence is claimed; required native useful
  witnesses can still refute this explicit policy.
- A present healthy empty information dictionary is authoritative; only checked
  absence advances to plain information. Information refusal affects ID, flags,
  development region and plain-name fallback; independent healthy localized
  resources may still supply a name. A preceding refused name candidate stops
  all later name fallback. LocProvenance consumes a top-level key/type record
  and any dictionary count check, never a language or recursive metadata walk.
  Every non-reserved table value must be a bounded dictionary even if unselected.
- The resource handle remains usable for later openat operations; a separate dup
  is transferred to fdopendir on success, or closed by the caller on failure.
  Retire selector/plans, dictionaries and no-copy CFData before their backing
  buffer, on every actual-return branch. Hold shared capacity through native
  return after caller cancellation. The normative lifecycle table is complete
  semantic work; concrete call/charge slots and opaque acquisition limits remain
  k220/N5/N8 obligations, not an inferred 32C/48F fit.
- A missing/nil selector result for a nonempty inventory must refuse the name,
  not become a healthy empty selection with plain-name rescue. A failing pure
  model case exposed that otherwise-permissive branch; the explicit result
  boundary now distinguishes absence of the observation from an observed array.
  The model consumes saved literal arrays and controlled dictionaries only;
  no CF function or installed target is run.
- D2 exports and the stable served URL carry the selected semantics and completed
  k217 choice. Browser creation reports iab unavailable and browser inventory is
  empty. Inspect local SVG rasterization instead; k221 explicitly owns unresolved
  browser deep-link/current-discussion/mobile/dark verification. Sips rendering
  mishandles SVG multiline text, so use installed rsvg-convert for visual checks;
  claim no browser-delivery pass from that conversion.
- Final frozen checks after source/export edits: reader-plan-check passes 59
  policy cases and strict pyright with zero errors; subject-check passes seven
  regressions and rejects six original-defect controls; localized-boundary-check
  retains/reproduces the historical pathname/layout/refuted-size/input/inventory/
  omitted-table controls; check:docs exits zero. All 763 declared repository
  markdown/JSON/GraphQL/D2/SVG/Python/HTML/Taskfile subjects match before/after
  item by item, recorded under .build/application-metadata-reader-plan-verification.
  These checks use saved census/selector values and controlled local fixtures,

  independent resources. Browser/mobile/dark verification remains with k221.
  No Koine build, probe, launch, source query, registration, consent, signing or
