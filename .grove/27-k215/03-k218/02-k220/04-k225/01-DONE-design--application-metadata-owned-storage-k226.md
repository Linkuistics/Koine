# application-metadata-owned-storage-k226

## Goal

Make explicit owned storage a checkable receipt contract, including scratch overlap
and every repeated read/write, and derive the known subterms for all saved episodes.

## Context

Consume the parent k225 charter and k224/k223 artifacts. This is the first child
of k225's dependency decomposition; the full source/root/bridge/wire composition
belongs to application-metadata-owned-wire-composition-k227. Selected budgets,
native dimensions, family hold and original k220/k218/k215 obligations all bind.

## Done when

- Define exact requested capacities, header/alignment/population/growth writes,
  explicit packed records and opaque versus borrowed/owned objects; distinguish
  this proposed storage from actual Swift bridge/COW layout.
- Check two immutable 128 KiB inputs, EOF, scalar/key/conversion scratch, selector
  vectors, growth overlap, final copies, no-refund cleanup and failing prefixes
  with a pure executable model. Reserve cleanup and bytes before optional work.
- Independently derive the known local input/key/vector subterms for every one
  of 2,043 episodes and both saved runs, preserving aliases, LocProvenance,
  rejected entries, 129-byte witness, 1,500-byte roots and all 149 outside paths.
  Expose unbound source/root/bridge/final fields as null, never total-fit claims.
- Freeze/hash inputs and compare rows, with isolated charge/growth/cleanup/
  unknown controls and existing source/root and original-defect checks. Use
  Taskfile. Present an editable rendered browser view. Native G/N/V pending.
- Retire only this child. K227 stays live; do not close k225/k220, remove the
  family hold, add fragment review or cut implementation.

## Decisions (running log)

- Packed capacities are a proposed explicit storage contract, not a measurement
  of Swift Array/String/Dictionary layout or replacement of k224's source/walk
  behavior. Gross is requested allocation capacity plus every performed read/
  initialize/write/copy; the same input capacity is allocated once per job and
  each read remains charged. Reserved unused bytes are not performed writes.
- The checked raw scratch partition requests 270,368 bytes once per job. Both
  complete saved runs reproduce known local subterms 14,181,924/14,356,031 gross
  and 401,979/404,815 attempts. Every raw direct entry, retained component,
  suffix-stripped selector key and table key (including LocProvenance) remains
  represented. These partial/superset terms establish no whole-job upper or
  runtime lower bound; missing source/root/bridge/owner/final/wire terms stay null.
  Exact-block storage is the inspectable proposal; no unproved arena/COW discount
  or actual Swift-layout claim is adopted.
- Frozen Taskfile checks pass: nine local contract tests, thirteen isolated
  omission/refund/alias/outside/unknown controls, strict Python types and complete
  item-by-item reproduction. Inherited source/root, episode, operation ledger,
  reader, saved subject and localized original-defect checks passed independently.
  The new SVG deep link was opened in Chrome and its readable start, body and
  live-composition ending inspected. The compact JSON preserves every cell and
  validates all ordered spelling associations before omitting duplicate strings.
  This child's Done when is satisfied; k227 remains live under k225, so neither
  k225 nor k220 closes and the whole-k215 hold/review/native G/N/V remain.
