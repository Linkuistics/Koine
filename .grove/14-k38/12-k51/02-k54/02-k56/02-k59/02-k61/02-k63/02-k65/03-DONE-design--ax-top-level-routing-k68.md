application activation to the captured receiver, or deliver the precise evidenced
conflict and recommendation required by k65 before policy/adoption.

## Context
- Read `docs/verification/direct-ax-endpoint.md`, including receiver allocation,
  transitions and the current reviewer reconciliation. Evaluate that review as
  evidence against the original parent contract, not as a replacement charter.
- `receiver-symbols.json` resolves current registration to local Mach allocation
  and bootstrap send-right registration, and the accessors to distinct actual

  Registration and `_AXUIElementUpdateServer` install/change that table; the
  exported MIG front end alone cannot establish every handler's behavior.
- Parent k65 used its one reviewer. No independent-review stage is scheduled.

## Decisions (running log)

- Evaluate an unmodified application's native Open/Save panel alongside its
  ordinary document window, recording public presenter PID, actual PID and
  kind/data independently. Reuse the admitted direct transport; no descriptor
  from another receiver becomes an effect target merely because its public PID
  matches. Native execution stays in TestAnyware clone `koine-k68-routing`.
- Spend this leaf's one reviewer on the concrete handler/descriptor contract
  against primary platform sources. Local work inspects loaded AppKit code and
  exercises the native panel; a second reading of the same report would not
  resolve the platform premise. Keep the inherited restoration conflict visible.
- Unmodified TextEdit's Open top-level descriptor is local (`coco`, eight-byte
  data, actual/presenter PID 772); its child is actual 781/presenter 772. Save
  appears as a local sheet. The exact current-provider child-to-window test
  rejects Open and accepts the document. Do not treat the remote descendant as
  a demonstrated accepted wrong-process effect or silently broaden that filter.
- AppKit's registered set/action callbacks decode local specifiers and invoke
  dynamic object handlers. Default window handlers call deminiaturize or
  makeKeyAndOrderFront; AXFrontmost calls currentApplication.activateWithOptions,
  which reaches WindowServer/Launch Services. Record the downstream binding as
  a distinct unestablished premise, not as a proved retargeting failure.
- Deliver the conditional receiver contract and concrete adoption conflict in
  `docs/verification/ax-top-level-routing.md`, with the existing restoration
  conflict still binding. No native mechanism, support narrowing or public
  contract is approved. k66 owns policy/adoption synthesis and k57 agreement.
