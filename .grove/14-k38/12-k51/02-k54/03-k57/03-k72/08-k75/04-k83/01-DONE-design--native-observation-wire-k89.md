# native-observation-wire-k89


## Goal

Inspect the actual AX observation registration and delivery code on pinned
platform bytes. Deliver a bounded wire-path map and a frozen discriminator for
the remaining lifetime/order/loss investigation, without claiming runtime
notification provenance from static code.



## Context

Consume k81, k82 and k88 and the repaired machine-spec observation proposal.
Reuse the read-only receiver/handler scanners from the earlier direct-endpoint
investigation. Their source and loaded-byte limitations must remain visible.

## Done when

- Identify registration, removal and notification ingress/egress entry points,
  traced destinations, receive-right ownership and relevant message forms, or
  name exactly which links remain unresolved before an encoder can be written.
- Pin OS, image identity, scanner inputs/executables and inspected raw bytes;
  execute only in a disposable TestAnyware clone and verify frozen subjects.
- Freeze both application-before-enumeration and element-after-enumeration
  schedules, delayed closure past reads of preparing and usable records,
  suppressed/saturated/failed delivery, reuse attribution and independent
  witnesses. Name falsifiers and distinguish missing evidence from impossibility.
- Preserve each remaining k83 obligation in live children before their native
  experiments; reconcile the design's current evidence boundary and visual
  discussion without adopting a mechanism or changing the served schema.

## Decisions (running log)

- Start with read-only inspection of this diagnostic process's loaded images.
  The scanner does not attach to targets, install callbacks or invoke scanned
  private function addresses. Freeze its symbol query before each bounded read;
  an adaptive follow-up is a new, separately hashed inspection, never an edit
  under a running measurement. Runtime closure and loss schedules belong to the
  following child, not this static slice.
- The inspected remote registration wrapper routes through cached process
  lookups; an owned request must explicitly preserve the admitted endpoint.
  The cookie constructor stores supplied values rather than establishing a
  window generation. The separate post path uses a zero-timeout send, supplying
  a concrete failed-delivery discriminator but no observer loss detector.
  Preserve these as bounded static findings; do not infer an authenticated
  closure, universal impossibility or native publication order from them.
- Spend the single in-session reviewer on the raw instruction/SDK basis of the
  report's wire, cookie, trailer and zero-timeout claims before they become a
  native encoder's input. The artifact and original contract, not this preferred
  interpretation, are its review material.
