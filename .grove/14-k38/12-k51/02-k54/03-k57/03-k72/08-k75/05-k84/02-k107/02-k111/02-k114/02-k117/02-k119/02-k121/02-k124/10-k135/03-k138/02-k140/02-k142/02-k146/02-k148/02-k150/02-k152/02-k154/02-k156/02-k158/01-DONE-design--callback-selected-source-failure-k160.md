## Decisions (running log)

- Use the existing Trace, Source and Ledger owners. Source failure is a cleanup
  cause only after its raw return and mandatory summary/drop/failure join; it is
  never a reason to interrupt a native call or invent successful retention.

  then service abort and reply according to both ledgers. This chooses one
  serialized failure path; independently racing controller aborts stay k159.
