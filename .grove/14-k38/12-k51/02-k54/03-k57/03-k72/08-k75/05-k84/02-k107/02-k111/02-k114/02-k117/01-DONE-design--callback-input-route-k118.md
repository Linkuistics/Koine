# callback-input-route-k118


## Goal
Establish the native normal-input marker and passive callback route in a
disposable clone before constructing capture transcripts around it.



## Context
Use the inherited witness contract and existing analyzer controls. This is a
bounded discriminator inside the existing native seam, not the complete recorder.

## Done when
- Build signed diagnostic controller, sampler and B/C target roles through the
  root Taskfile; target input records own PID and delivered payload independently.
- Identify callback mechanism, marker carriage, permission attribution and loop
  observations from source and native results, including a missing-input control.
- Run analyzer controls before native execution. Freeze probe, commands, marker
  schedule and signed bytes; retain raw logs, exits and itemwise digests.
- Establish or falsify ordinary marker receipt followed by a separate passive
  callback trigger, without sampler AX consent. A denied or unreached route is
  evidence of a specific gap, never a capture success or source-freshness result.
- Record result/limitations in the existing assessment and visual discussion;
  hand every remaining k117 criterion to its integration child.

## Notes
No getter, task-name acquisition or capture event is emitted by this probe.
Input Monitoring for the sampler and controller injection permission are
diagnostic permissions, not a product permission agreement. Preserve k119 live.

## Decisions (running log)

- Use a listen-only session-tail tap on the main run loop for this route-only
  discriminator. Its separately launched sampler reports Input Monitoring
  allowed and AX/post permission absent; the controller has separate injection
  permission. This does not choose the source or authorize product permissions.
- The first frozen run did not reach injection: advisory target activation
  produced no activation notification, and final target image snapshots failed.
  Preserve it as instrument-unreached. A separate LaunchServices reopen then
  produced actual target activation. Add that setup step, enlarge the diagnostic
  image manifest ceiling, record image count, and refreeze before measuring.
- One bounded reviewer found two valid reporting defects. Distinguish received
  event fields from controller-generated fields; label terminal outcome as
  intended before final flush/close, not actual process exit status. Correct the
  contract before the renewed run. Full external exit/watchdog evidence remains
  part of k119's integrated instrument; no second reviewer is required for these
  direct provenance wording corrections.
- The next frozen runs exposed event reuse: the second Unicode changed while
  both native recipients retained the first numeric marker. Preserve those
  failures. A fresh event source, configured before fresh event creation for each
  marker, passes the same payload checks in two ordinary runs after the negative
  control. This correction is covered by the native discriminator itself.
- Final ordinary/repeat receipts match B's own row and the sampler's distinct
  trigger; missing receipt withholds the trigger. All streams finish, named
  host/guest digests match, and sampler reports AX false/listen true/post false.
  This settles only the route prerequisite. Record actual guest runner exits
  separately from application intended outcomes; retain k119 for complete causal
  capture, child exits/watchdog and full native dependency obligations.
