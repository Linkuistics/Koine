# callback-recorder-contract-k125


## Goal
Specify the integrated diagnostic recorder's real field producers, enclosing
callback-return boundary, actual exits and whole-clone containment before native
capture measurement depends on them.

## Context
Consume the k118 route, k120 causal schema and k123 exit observer through the
capture assessment. Their native/synthetic evidence does not establish an
integrated capture path. No product implementation, permissions or public seam
changes are commissioned.

## Done when
- Write one concrete diagnostic contract covering paired messages, both source
  pairs and constructions, owned-right validation, post-return C input and B
  retention, a field-producer audit and its falsification cases.
- Specify independently observed exits and bounded failure handling, including
  pre-registration failure, unexpected membership and guest-supervisor failure;
  distinguish containment from missing status and capture success.
- Specify freeze/provenance subjects, complete native matrix and executable
  verification obligations without claiming that proposed checks have run.
- Update the assessment and browser views, verify presentation, and preserve
  every k121/k124 criterion in the native follow-on and node brief.

## Notes
The artifact is an experiment contract under docs/verification, not an agreed
product spec or ADR. Complete only this first child after decomposition. Native
execution remains callback-recorder-native-k126; k124 and k121 stay live.

## Decisions (running log)
- Use a same-thread enclosing CFRunLoopRunInMode return statement as the proposed
  returned producer. Callback depth flags and queued workers alone cannot prove
  unwind. Native nested-loop and early-acknowledgment controls must falsify the
  collector before its records can be credited.
- Retain the closed causal schema and require a separate bounded native audit
  verifier with complete joins. The current checker cannot grade per-call hint,
  native status, loop provenance or external process outcomes by itself.
- Give every native case a fresh disposable clone and require host-confirmed
  stop before acceptance or progression. This contains pre-registration and
  group-escape failures at the VM boundary; it does not replace missing per-app
  exit statuses, and incomplete cases remain incomplete.
- The one in-session reviewer found two valid/actionable gaps: post-return
  activation lacked causal edges into B/C activity, and mode-specific observers
  could miss nested servicing. Add paired target barriers and an unobserved-mode
  control with explicit inconclusive coverage. These substantive corrections
  earn tree review `callback-recorder-contract-k127` before native k126; no second
  in-session review. The native coverage mechanism remains an open premise.
- The unchanged causal analyzer rejects the synthetic missing-barrier trace with
  exit 2/ambiguous-activity and accepts the paired-barrier trace with exit
  0/consistent. Frozen inputs match itemwise; neither is native evidence. Both
  new views render and their fresh Safari deep links were checked in the isolated
  presentation clone, which was stopped and removed. Native work stays live.
