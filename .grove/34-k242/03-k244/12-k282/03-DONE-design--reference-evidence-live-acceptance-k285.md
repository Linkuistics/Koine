Keep qualification disarmed through provisioning, corrections, last-edit requalification,
independent audit and distinct k244 close. A separate independent release owner then
accepts the exact closing basis; only that owner's still-live commissioned supervisor
can originate a single k245 LIVE launch. Pure entries have only SCRATCH endpoints. A
release record is not a bearer credential or an automatic role selector. This preserves
k270's cooperative scope and k281's prohibition on tests selecting LIVE; it adds neither
another permit nor privilege. Receipt-driven arming and proof-driven automatic arming
are rejected because both leave the original pure-to-LIVE miswire reachable.

Inspection-only review remains findings-only. K269 must charter an independent
acceptance/registration owner after each required review and earned integration, on both
clean and findings paths. That owner reads original reviewed/final bytes, findings and
every disposition, independently adjudicates them, then opens its own commissioned
registrar channel for its own scope-preserving trust act. It is neither the producer nor
the repairer whose changes it accepts. Clean review requires acceptance, not invented
integration. Commissioning/bootstrap and verifier-self controls have separately owned
original results and an explicit terminal trust act, without candidate self-certification.
These are concrete procedures within k270's existing delegated approval route; wider
authority still returns to Antony. No acceptance or commissioning occurs in this leaf.

Use the existing durable evidence contract and whole-byte companions, not a parallel
spec or new ADR for this reversible pre-provisioning repair. The relevant argument
surface removes public mode selection; the state table and isolating counterexamples
make remaining release/order obligations reviewable. No formal model or extra review
programme is commissioned. K286 retains full enduring-input partition and k287 whole
reconciliation/review; this seam alone is non-consumable by k269.
