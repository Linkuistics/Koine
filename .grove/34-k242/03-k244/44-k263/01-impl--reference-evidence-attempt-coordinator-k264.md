# reference-evidence-attempt-coordinator-k264

## Goal

Compose the durable attempt protocol and fixed preflight boundary, with working
pure qualification and output-only packaging recipes verified without target use.

## Context

Consume all four earlier increments and the canonical selected permission. Packaging
requires installed macOS 27.0.1 (26A434) and matched qualified instrument/verifier/
schema/fixture/configuration/compiler/SDK/runtime-image/tool/input/permission identities.

## Work and verification

1. Implement AttemptCoordinator.swift, fixed packaging entry and separate pure-test
entry. Packaging accepts only a fresh output destination; it exposes no arbitrary
query/root/file/language/test-adapter/retry/resume/force option. Documentation/help
states a started failed/interrupted attempt consumes the pass and forbids automatic retry.
2. Before target contact, check exact installed build and complete independently
verified qualification proofs, tool/input identities and frozen permission. Wrong/
unavailable/mismatched checks or prior output/start refuse with no target spawn,
lookup/listing/read. Never let a user-supplied success bit or raw total admit the pass.
Bind the frozen one-pass permission to its declared attempt/destination and check
any prior acquisition-start evidence for that permission. A second fresh output
name cannot reset spent authority. Keep this evidence in the attempt records,
without adding a session-status file; any unestablished prior-attempt check refuses.
3. Enforce this phase order: admission and durable attempt/start; complete initial
source terminal/reap/framing; initial held-root/layout/inventory/file acquisitions;
complete closure source and its held-root associations; full item inventory/identity/
byte rereads and comparisons; final input/image freeze; final closure publication.
Each phase requires its predecessors; an aborted phase leaves later work explicitly
unperformed, never retries or repairs an initial loss from closure bytes. Exercise
out-of-order phase mutations against intended stable rejection coordinates.
Exclusively create attempt header and persist acquisition-start before source spawn.
One writer owns write-once object/observation segments; interrupted temporary segments
and actual prefix extents survive. Final closure requires terminal/reap, input/image
freeze and all per-item comparisons. Missing final closure is interrupted/incomplete.
4. Verify real scratch output durability, exclusive writer/output refusal and process
death at header/start/read/closure/publication boundaries. Inject launch/pipe/read/
allocation/storage/cleanup/tool-change failures; preserve exact missing work and
no retry/newer-byte substitution. Offline replay cannot resume target acquisition.
5. Add working Taskfile entries evidence:reference-build,
evidence:reference-qualify and evidence:reference-package. The qualify entry reaches
only pure emitters/scratch roots/fault composition, never packaging as a dependency.
Package accepts OUTPUT only and uses fixed real adapters after admission. Its
recipe executes the retained qualified executable; it has no rebuild dependency.
Store that artifact with its actual build inputs/digests. A later rebuild is a
different candidate: require exact executable equality and all other matched
identities, or complete fresh qualification before admission. Source equality alone
cannot admit it. Qualification separately verifies matched runtime-image continuity.
Exercise identical coordinator admission/success/failure through internal pure
composition; never invoke the actual packaging recipe during tests.
6. Verify all new tasks that are safe here, validate package argument/build/preflight
behavior through pure tests, and document the deferred k245 real invocation.
Proof/output inventory freezes all subjects/tools before/after, not just executables.

## Done when

The coordinator's pure complete and interrupted attempts are independently replayable;
preflight refusal happens before any forbidden contact. Actual runnable Taskfile
recipes exist with the separated dependency boundary. Packaging still refuses target
admission until k265 delivers matching complete proofs; this leaf spends no pass.
