## Decisions (running log)

The canonical evidence report remains the cohort/selection/eligibility owner. A
linked verification contract will own the detailed evidence representation and its
independent control obligations; neither duplicates the application job protocol.
Original file bytes and raw source/inventory sequences are authoritative. Typed
trees and reader-fact witnesses are separately qualified derived observations,
with decoder identity and explicit unavailable/refused limits. Normalization cannot
replace original serialization or establish native reader semantics.

This first child specifies the instrument's complete pure qualification matrix;
the next child builds and observes those controls before any authorized target read.
The existing executed hashes remain packet-integrity evidence only. A passing
contract/render/reconciliation check is not instrument qualification.

The complete record/control design is in application-reference-evidence.md, linked
from the canonical report and architecture viewer. The existing renderer task now
renders both the new contract and revised joint-evidence boundary. Legacy capture
guidance is reconciled so it cannot be mistaken for the authorized new package.
No ADR is added: original-byte preservation follows the accepted requirements;
the detailed representation belongs in the verification contract rather than a
second statement of the existing accounting/eligibility decisions.
