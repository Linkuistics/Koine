# reference-evidence-held-acquisition-k259 — brief

## Goal

Collect complete closed-layout evidence and exact item closure from held scratch
roots while proving component scope and forbidden-contact behavior.

## Done when

Literal/resolved component bounds, held ancestry, ordered layouts, raw direct locale
inventory, all fixed file occurrences and complete/partial immutable bytes are
implemented through real descriptor operations and fault seams. Every logical
copy/base/locale/source/helper/alias relation survives object sharing. Full before/after
item reads and identity/inventory associations detect changes without retry/fallback.

## Decomposition

Held-roots-k260 is a usable scratch-root/layout inspector with complete no-contact checks.
Fixed-files-k261 adds the complete fixed-file/direct-locale package and decoder witnesses.
Item-closure-k262 adds independent full rereads, actual held-root associations for
both source phases, physical alias checks and item-by-item association closure.
An inspector or pre-closure package never reports successful stable complete acquisition.

## Pointers

Read the descriptor-relative ADR and the durable contract's closed acquisition,
records, freeze and replay limits. Own Sources/ReferenceEvidence/HeldAcquisition.swift,
FileAcquisition.swift and ItemClosure.swift, the package's descriptor tests and
Fixtures/ReferenceEvidence/filesystem plus independently authored contact expectations.
Reuse the prior stages' envelope, decoder and occurrence interfaces without a provider dependency.

## Notes

Pure composition starts from held constructed scratch fixtures; simulated permission
roots are test-only. Packaging must still enforce both real literal and resolved
/System, /Applications or /Library bounds before listing/bytes. This is no new production
walk, evidence cap or native no-dialog/hydration qualification.
