# reference-evidence-metadata-witnesses-k255

## Goal

Export every metadata candidate, flag, complete table/LocProvenance and joint tail
from the qualified native tree, with separately checked exact coordinates.

## Context

Consume native-types-k254's actual decoder and replay-k250's independent oracle.
Complete original bytes and decoder-derived branches remain separate outcomes.

## Work and verification

1. Freeze pure information/strings/loctable specimens for both name keys with
absent/empty/usable/non-string alternatives; identifier, development-region,
executable/version and LSUIElement/LSBackgroundOnly with full non-string/non-Boolean
values. Include nested dictionaries/arrays/data/date/reals and extra unselected keys.
2. Implement MetadataWitnesses.swift and package tests. Every branch cites its
file/object/tree coordinate and full associated tagged value. Preserve complete
trees; selected candidates never delete rejected facts.
3. Cover all raw table keys/values, every dictionary member/language and both
candidates, global/per-locale/platform/plain families, and complete LocProvenance
of any type. Base remains its distinct selection branch.
4. Produce exact byte/code-unit tails for all file/direct-component/key/candidate
observations with their source/copy/file/tree/branch links. UTF-8 length is derived
only through exact conversion; failure retains UTF-16 and an unavailable length.
Maxima are derived references, not invented padding or unattached numbers.
5. Independently verify complete positives and targeted omitted/coerced/reassigned
equal-length losses on ordinary, helper and alias-linked specimens. Add/verify
task evidence:reference-witness-check with frozen inputs and actual per-case proof;
retain native-types and replay checks.

## Done when

Complete typed witnesses and joint tails are usable on pure file objects through
the version-1 schema. Omitted unselected facts and association swaps fail the
independent oracle even with equal totals. Required typed failures stay explicit.

## Notes

This is neither an independent useful-app classifier nor the Koine selected reader.
No production file clipping or selected-language subset is applied to evidence.
