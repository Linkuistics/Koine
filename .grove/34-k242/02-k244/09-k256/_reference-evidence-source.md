# reference-evidence-source-k256 — brief

## Goal

Produce lossless source observations and per-occurrence initial/closure comparison
using the actual concurrent pipe runner on pure emitters.

## Done when

Every emitted byte and repeated/empty/outside/malformed slot, independent stderr
stream and actual launch/EOF/termination/reap fact is retained. Failure never enables
acquisition. Complete source permutation positives preserve both sequences and
occurrence correspondence; changed membership/multiplicity fails at the intended
coordinate. Actual held root/physical alias association is completed by k262 after k260.
Actual pipe tests and injected failures agree with independent expected contact traces.

## Decomposition

Pipe-runner-k257 implements framing and real concurrent process observation together.
Source-closure-k258 compares complete before/after source occurrences and permutations.
The first can be demonstrated against a pure emitter without the comparison feature.

## Pointers

The durable contract fixes source framing and the argument vector.
Own Sources/ReferenceEvidence/SourceRunner.swift and SourceClosure.swift inside the
standalone tool, its package tests and Fixtures/ReferenceEvidence/source-emitter.
Use replay-k250's record/verification interface and decoder-k253's existing checks.

## Notes

Do not run mdfind. An internal test composition chooses only a scratch emitter;
the future packaging composition pins /usr/bin/mdfind and its exact fixed arguments.
No arbitrary source/path/query flag is exposed by packaging. Closure is never retry.
