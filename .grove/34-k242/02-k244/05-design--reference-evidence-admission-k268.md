## Goal

Repair the complete admission and qualification design before construction consumes
it. Resolve the cross-cutting gaps externalized by reference-evidence-instrument-k267
without implementing a tool or spending the one target pass.

## Design questions

- F1: Give prior-start admission a defined authoritative subject independent of
  caller-selected output. Cover concurrent attempts and moved/deleted/unreadable
  evidence, uncertain first use and durable start before contact. Keep actual attempt
  evidence, no session-status artifact or automatic reset. State the enforceable
  boundary and adversarial/tamper limits. If the existing permission cannot support
  it, ask Antony about the concrete trade-off; recommend fail-closed admission with
  explicit new authority for uncertainty rather than silently expanding this pass.
- F2/F3: Define the closed qualification proof schema, independently required
  applicability inventory, admission verifier and who invokes it. Reject incomplete
  proofs against an independently frozen inventory, including schema-valid omissions.
  Partition qualified executable/configuration/permission inputs from reporting
  outputs. State exactly how the fixed permission is represented and compared with
  the canonical requirements. Reconciliation cannot mutate a measured input and
  inherit its proof; neither can writing a proof identity into a pinned document.
- F4/F5: Select realizable observation outside the producer's wrappers for real
  pipe/syscall contact, with a deliberate direct-bypass control. Define how the exact
  fixed packaging composition, constants and task edges can be exercised without
  mdfind or installed-root contact. Observe deliberate pure miswiring fail before
  contact. Static inspection/mock-only/producer traces alone are insufficient.
  If the observer cannot be qualified within authorized pure scope, retain that
  exact unavailable boundary rather than substituting target experimentation.
- F9: Distinguish independent byte-format/type/position expectations, independently
  acquired pinned runtime observations and regression evidence learned from output.
  Define corroboration for CF acceptance/storage/duplicate survivors/coercion/date/
  NaN observations without calling a copied producer tree an independent oracle.
- F11: Specify the inherited literal/resolved component rule for documented data-
  volume, mount, firmlink and cryptex/link specimens. Identify what a held walk can
  actually observe and its limits. No current topology probe is authorized. Do not
  introduce a narrower /System policy or broader root set from historical mounts;
  any permission change needs a concrete decision from Antony.
