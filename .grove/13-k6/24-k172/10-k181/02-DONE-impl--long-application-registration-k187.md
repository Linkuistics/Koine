## Goal

registered-long/both-order and preferred-long subjects. Accept only actually
observed preconditions and effects. Preserve v1: the hand-off of a long literal,
expanded or resolved spelling is refused, never rescued by a running short copy.

  with the link's target text itself below 1,024 bytes. Append the remaining
  components to that short link so the registration argument and its Info.plist
  pathname fit the platform limit, while the resolved copy is still long.
  This is a disposable registration fixture, never a production hand-off route.
- Read actual NSWorkspace preferred/listed values and independently establish
  the physical copy's identity and expanded/resolved length. A command exit 0,
  a short alias value alone or an inferred order does not establish a precondition.
- Where admitted, test short constrained copies with the unequal physical long
  copy actually before and after the selected copy in the observed enumeration.
  Test a physically long preferred copy for unconstrained launch/named open,
  cold and with a short copy running, with controlled observers, exact guidance
  for the actual refused spelling kind/count, no substitution and kernel receipts
  on admitted short workflows. Record the native selection immediately before
  each request so running-copy preference cannot silently change the subject.

## Decisions (running log)

- The mandate supplies the fixture design and authorizes this AFK implementation.
  Use one midpoint prefix link per 1,024/1,500-byte physical copy, with link text,
  registration argument and appended Info.plist pathname all below 1,024 bytes.
  The fixed matrix is the six permutations of A/B/long at each length (12 states),
  preceded by public unregistration of A/B/both long routes. Read native values
  after every operation; invocation order never proves enumeration order.
- The graph CLI cannot start: an active pre-coordination/unverified generation
  refuses it. Read the bounded fixture/observer scripts directly; no graph
  freshness, coverage or completeness claim is made.
- Reuse the signed 1.0.1 packaged app, prepared image and installation request
  observer. A component-relative observer independently joins native paths to
  the measured bundle identities and physical spellings. Request-local snapshots
  establish native selection after running-copy setup and immediately before
  each send. Test each admitted physical order and preferred-long state once per
  length/operation/running state; missing preconditions stay pending.
- Spent the sole reviewer on measurement validity before running the VM. All
  four findings were actionable: strict complete effect-observation arrays and
  guest instance/ps/log failures; exact request-local short-running incarnation;
  changed short-preferred preconditions recorded as pending; corruption controls
  for the new native/refusal predicates. The repairs have executable controls
  rejecting missing arrays, wrong native order/identity/preference, spelling/count,
  delivery/process change and wrong/missing running incarnation. These seams

  `$length` shadows the builtin `length`. Renamed the parameter to

  controls are supporting instruments only, never V acceptance.
