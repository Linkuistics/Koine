short A/B's identifier. K186's absolute, relative-cwd and full-target-link
attempts did not expose them. K187 then constructed one valid prefix link per
length (435/837-byte target text, 624/698-byte registration arguments,
644/718-byte Info.plist pathnames), independently established their physical
identity and expanded length, and completed all six A/B/long public registration
orders per length, unregistering all four routes before each state.
Every long registration returned scan error -37 / exit 1; every final NSWorkspace
query lists only A then B and prefers A. Every intermediate native path was
physically short, or the query reported none while short copies were unregistered.
This is bounded observed unavailability, not an impossibility theorem for macOS.

copy actually before and after the selected short copy for constrained launch/
named open; and a physically long preferred copy refused cold and with a short
copy running for unconstrained launch/named open. L/G cover the contract but
cannot pass V. K187's raw run later stops at a recipe-only reveal matcher; the
complete native matrix and all 55 unchanged pre-run input entries are retained.
No new Finder selection acceptance or whole-run pass is claimed.
